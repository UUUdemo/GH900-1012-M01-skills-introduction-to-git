# Stack Overflown

AAAA這是一個以開發者主題為靈感的方塊消除遊戲。玩家需要操控落下的程式區塊，將它們排列成指定的錯誤模式，讓畫面中的「bug」被清除，避免堆疊過高導致遊戲結束。

## 遊戲功能

- 落下方塊的經典俄羅斯方塊式操作
- 每一局都會隨機出現一個目標錯誤模式
- 透過排列方塊符合 5x5 的錯誤圖樣來清除區域
- 依照完成模式的次數累積分數
- 支援暫停、重新開始與鍵盤操作
- 視覺風格使用開發者常見的配色與錯誤名稱，例如 Null Pointer、Memory Leak、Off By One 等

## 玩法目標

你需要在板面上拼出目標圖形，當符合指定的錯誤模式時，系統會清除整個區域並加分。只要堆疊持續增加，最終就會觸發「STACK OVERFLOW!」結束遊戲。

## 控制方式

- 左右方向鍵：移動方塊
- 上方向鍵：旋轉方塊
- 下方向鍵：快速下落
- 空白鍵：直接落下
- P：暫停／繼續

## 執行方式

這個專案是純前端應用，直接開啟瀏覽器即可遊玩。

1. 進入專案資料夾
2. 打開 `src/index.html`
3. 或使用本機伺服器：

```bash
cd src
python -m http.server 8000
```

接著在瀏覽器開啟：

```text
http://localhost:8000
```

## 專案結構

```text
src/
  index.html   # 遊戲畫面與 UI
  index.js     # 遊戲邏輯、方塊移動、判定與分數
  patterns.js  # 目標錯誤模式資料
  style.css    # 頁面樣式
```

## 技術說明

此 app 由 HTML、CSS 和 JavaScript 構成，沒有額外依賴，適合拿來練習前端互動、Canvas 繪圖與簡單遊戲邏輯設計。
